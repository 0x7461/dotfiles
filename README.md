# dotfiles

chezmoi source. `main` tracks the current install; the archive tags are frozen snapshots of earlier ones.

## Branches

- **`main`** — live chezmoi source for the current install (Void Linux + niri).

## Archive tags

Pre-chezmoi snapshots of earlier installs; their install notes now live in a private vault.

- **`archive/arch`** — Arch Linux
- **`archive/arch-wayland`** — Arch Linux + Hyprland
- **`archive/windows`** — Windows
